## Codebase Patterns
- Package root: `prospector/` with subpackages `ingest/`, `spectral/`, `scoring/`, `ephemeris/`
- pytest configured via `pyproject.toml` with `testpaths = ["tests"]` and `pythonpath = ["."]`
- Scoring YAML configs go in `scoring/` directory (project root, not inside `prospector/`)
- Data files are gitignored (`data/`); create subdirs programmatically in ingest modules
- Python 3.11.8 available on system (no venv currently; `env/` in .gitignore)
- Database access: `prospector.db.get_connection(":memory:")` for tests, `get_connection()` for default file DB
- BLOB round-trip: `array.tobytes()` to store, `np.frombuffer(blob, dtype=np.float64)` to read
- Schema is idempotent (`CREATE TABLE IF NOT EXISTS`) — safe to call `init_schema()` multiple times
- SBDB ingest: `from prospector.ingest.sbdb import ingest_sbdb_csv` — takes csv_path + conn, returns row count
- SPK-ID mapping: numbered asteroids spkid ∈ [2000001,2999999] → asteroid_id = spkid - 2000000; others pass through
- Use `INSERT OR REPLACE` for idempotent ingestion — safe to re-run on same data
- Column names normalized to lowercase in ingest — handles case variations in CSV headers
- NEOWISE ingest: `from prospector.ingest.neowise import ingest_neowise` — takes filepath + conn, returns row count
- NEOWISE cross-match: IAU number first (from preloaded set), designation fallback (DB lookup)
- FK-safe ingestion: preload `known_ids = set(row[0] for row in conn.execute("SELECT asteroid_id FROM asteroids"))` before inserting into child tables
- Column alias resolution: `_resolve_columns()` pattern — try explicit map first, then known aliases list, case-insensitive
- astropy available via astroquery dep — `from astropy.io import ascii as astropy_ascii` for IPAC table format
- classy taxonomy: `pip install space-classy tf-keras 'tensorflow-probability==0.24.*'`; import as `import classy`
- classy API: `classy.Spectrum(wave=arr, refl=arr, pV=albedo)` — albedo MUST be `pV=`, NOT `albedo=`
- classy classification: `spec.classify(taxonomy='mahlke')` → `spec.class_mahlke` (label) + `spec.class_A..Z` (17 probabilities)
- classy Mahlke classes: A, B, C, Ch, D, E, K, L, M, O, P, Q, R, S, V, X, Z
- classy requires numpy<2.0 — use isolated venv; set ROCKS_CACHE_DIR env var for automated runs

- Created `prospector/ingest/neowise.py`: NEOWISE PDS SBN diameter/albedo → physical_properties table
- Key function: `ingest_neowise()` — reads CSV or IPAC table format, cross-matches to existing asteroids
- Supports flexible column name resolution with aliases (handles varying PDS SBN column names)
- Cross-match: IAU number (preferred, checked against preloaded known_ids set) → designation fallback (DB lookup)
- FK-safe: preloads known asteroid_ids to avoid IntegrityError on child table inserts
- 32 tests in `tests/test_ingest_neowise.py`: unit tests for helpers + integration tests with sample data
- **Learnings for future iterations:**
  - Preload `known_ids` set before batch insertion into FK-constrained child tables — avoids IntegrityError
  - `_resolve_columns()` pattern: map logical names → actual DF columns via explicit map + alias fallback — reusable for any variable-format input
  - NEOWISE PDS SBN uses IPAC table format (.tab) — `astropy.io.ascii.read(path, format='ipac')` handles it
  - For cross-matching without entity-resolver: number match covers >95% of cases; designation fallback covers the rest
  - Test fixtures: create `db_with_asteroids` fixture that pre-populates asteroids table for downstream ingest tests
