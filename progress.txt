## Codebase Patterns
- Package root: `prospector/` with subpackages `ingest/`, `spectral/`, `scoring/`, `ephemeris/`
- pytest configured via `pyproject.toml` with `testpaths = ["tests"]` and `pythonpath = ["."]`
- Scoring YAML configs go in `scoring/` directory (project root, not inside `prospector/`)
- Data files are gitignored (`data/`); create subdirs programmatically in ingest modules
- Python 3.11.8 available on system (no venv currently; `env/` in .gitignore)
- Database access: `prospector.db.get_connection(":memory:")` for tests, `get_connection()` for default file DB
- BLOB round-trip: `array.tobytes()` to store, `np.frombuffer(blob, dtype=np.float64)` to read
- Schema is idempotent (`CREATE TABLE IF NOT EXISTS`) — safe to call `init_schema()` multiple times
- SBDB ingest: `from prospector.ingest.sbdb import ingest_sbdb_csv` — takes csv_path + conn, returns row count
- SPK-ID mapping: numbered asteroids spkid ∈ [2000001,2999999] → asteroid_id = spkid - 2000000; others pass through
- Use `INSERT OR REPLACE` for idempotent ingestion — safe to re-run on same data
- Column names normalized to lowercase in ingest — handles case variations in CSV headers
- NEOWISE ingest: `from prospector.ingest.neowise import ingest_neowise` — takes filepath + conn, returns row count
- NEOWISE cross-match: IAU number first (from preloaded set), designation fallback (DB lookup)
- FK-safe ingestion: preload `known_ids = set(row[0] for row in conn.execute("SELECT asteroid_id FROM asteroids"))` before inserting into child tables
- Column alias resolution: `_resolve_columns()` pattern — try explicit map first, then known aliases list, case-insensitive
- astropy available via astroquery dep — `from astropy.io import ascii as astropy_ascii` for IPAC table format
- classy taxonomy: `pip install space-classy tf-keras 'tensorflow-probability==0.24.*'`; import as `import classy`
- classy API: `classy.Spectrum(wave=arr, refl=arr, pV=albedo)` — albedo MUST be `pV=`, NOT `albedo=`
- classy classification: `spec.classify(taxonomy='mahlke')` → `spec.class_mahlke` (label) + `spec.class_A..Z` (17 probabilities)
- classy Mahlke classes: A, B, C, Ch, D, E, K, L, M, O, P, Q, R, S, V, X, Z
- classy requires numpy<2.0 — use isolated venv; set ROCKS_CACHE_DIR env var for automated runs
- Entity resolver: `from prospector.ingest.entity_resolver import resolve` — takes any identifier string + optional conn, returns ResolvedID(asteroid_id, designation, packed, source)
- MITHNEOS ingest: `from prospector.ingest.mithneos import ingest_mithneos_dir` — takes dirpath + conn, returns spectrum count
- Spectral ingest pattern: read file → parse filename for identity → resolve to asteroid_id → FK check → store as numpy BLOBs
- MPC pack/unpack: `pack_designation("1998 SF36")` → `"J98S36F"`, `unpack_designation("J98S36F")` → `"1998 SF36"`
- Spectral preprocessing: `from prospector.spectral.preprocessing import preprocess_all, preprocess_spectrum`
- Stage 0 pipeline: resample → normalize (550nm) → mask telluric (ground-based) → estimate SNR → assess quality → update DB
- Default grid: `DEFAULT_GRID = np.arange(0.35, 2.55, 0.005)` — 440 points at 5nm spacing
- Ground-based surveys for telluric masking: `GROUND_BASED_SURVEYS = {"MITHNEOS", "SMASS"}`
- Quality flags: 'good' (SNR≥25, coverage≥1.5μm), 'low_snr' (SNR<25), 'partial' (narrow coverage)
- Normalization falls back to nearest valid wavelength when 550nm is out of range (e.g., NIR-only spectra)
- Taxonomy classification: `from prospector.spectral.taxonomy import classify_spectrum, classify_all`
- classify_spectrum returns dict: {'class', 'prob', 'probabilities', 'prob_vector'} or None
- classify_all processes only asteroids with normalized spectra not yet in taxonomy table
- Taxonomy prob_vector: numpy BLOB of 17 floats in MAHLKE_CLASSES order (A,B,C,Ch,D,E,K,L,M,O,P,Q,R,S,V,X,Z)
- Coverage detection: 'vnir' (vis+NIR), 'vis_only', 'nir_only' based on wl_min/wl_max thresholds
- Mock classy in tests: `patch.dict("sys.modules", {"classy": mock_classy})` pattern — avoids tensorflow dependency in test suite
- Band analysis: `from prospector.spectral.band_analysis import analyze_all, analyze_spectrum`
- Band analysis eligibility: SILICATE_CLASSES = {S, Q, K, A, L, O, R, V} + normalized spectrum + wl_max >= 2.0 μm
- Band analysis stores results in band_analysis table: band1_center, band2_center, bar, ol_opx_ratio, fa/fs_mol_pct, gaffey_subtype, calibration
- Gaffey subtypes: S(I)-S(VII) zone classification; only S(IV) gets Dunn calibration (dunn2010), others get gaffey1993_zone
- Telluric NaN gaps handled naturally by polynomial fitting — find_band_center interpolates through gaps
- Temperature correction: T ≈ 280/sqrt(a) K; band centers shift by ~5.7e-5 (BI) and ~1.0e-4 (BII) um/K relative to 300K lab
- Granvik prior: `from prospector.scoring.granvik_prior import taxonomy_prior` — takes (a, e, i_deg), returns 17-element numpy array
- Granvik prior output is BLOB-compatible with taxonomy.prob_vector — scorer can treat both uniformly
- Scorer: `from prospector.scoring.scorer import score_all, score_asteroid` — Monte Carlo composite mining score
- score_all(conn, mode, n_samples) writes to scores table; uses COALESCE(o.diameter, pp.diameter_km) for diameter fallback
- score_asteroid returns dict with composite_score, estimated_mass_kg, grade_estimate, target_material, material_contributions
- Recoverability factors: Phase 1 defaults in scorer.py; Phase 2 will load from YAML config
- Gaia DR3 ingest: `from prospector.ingest.gaia import ingest_gaia_file, ingest_gaia_tap` — TAP query or local CSV/VOTable
- Gaia table `gaiadr3.sso_reflectance_spectrum`: one row per (source_id, wavelength) — 16 bands per asteroid, wavelength in nm
- SMASS ingest: `from prospector.ingest.smass import ingest_smass_dir, ingest_smass_file` — reuses MITHNEOS reader
- Gaia cross-match: `number_mp` → IAU number (preferred), `denomination` → entity_resolver (fallback), skip `Gaia-DR3SSO-*` internal IDs
- Gaia quality flags: 0=good, 1=poor, 2=compromised — `skip_compromised=True` filters all-compromised spectra
- RELAB ingest: `from prospector.ingest.relab import ingest_relab_dir, ingest_relab_file` — PDS4 .tab/.xml pairs
- RELAB stores in `lab_spectra` table (no asteroid FK) — meteorite samples join conceptually via meteorite_type → taxonomy class
- RELAB PDS4 XML namespace: `speclib` = `http://pds.nasa.gov/pds4/speclib/v1` — use `specimen_id`, `specimen_name`, `specimen_type`, `rock_subtype`
- RELAB tab files: wavelength in nm (convert to μm), reflectance — 2-column fixed-width ASCII
- RELAB meteorite identification: `specimen_type` contains "Meteorite" (values: "Other Meteorite", "Ordinary Chondrite", "Meteorite")
- RELAB rock_subtype has multiple values: first=group (e.g., "Carbonaceous Chondrite"), second=type (e.g., "CM2")
- Space weathering: `from prospector.spectral.weathering import deweather_all, fit_cs, deweather_spectrum`
- Brunetto model: R_obs = R_fresh × exp(Cs/λ); Cs < 0 for reddening; deweather = R_obs × exp(-Cs/λ)
- Cs fit: least-squares ln(R_norm) vs 1/λ in continuum regions (0.50-0.70, 1.25-1.35, 2.20-2.50 μm)
- Weathering columns added via `_migrate_add_columns()` in db.py — ALTER TABLE IF NOT EXISTS pattern
- Deweathered BLOB stored alongside original reflectance — band_analysis can prefer deweathered when available
- Curve matching: `from prospector.spectral.curve_match import find_analogs, match_all, match_spectrum`
- find_analogs(asteroid_id, conn, top_n=5) returns list of dicts with wmse, rho, scale_factor, taxonomy_weight
- match_spectrum(wl_ast, refl_ast, wl_lab, refl_lab) resamples to overlap, applies free scaling, computes WMSE + ρ
- Taxonomy-meteorite mapping in TAXONOMY_METEORITE_MAP: S→{OC,Iron}, C→{CC}, M→{Iron}, V→{HED}, etc.
- RHO_THRESHOLD = 0.90; constant spectra (zero std) get rho=1.0 if WMSE≈0
- CNN mineral: `from prospector.spectral.cnn_mineral import predict_all, predict_spectrum, assess_agreement`
- CNN grid: 0.45-2.45μm at 5nm (401 channels); resample via scipy.interpolate.interp1d
- PyTorch is optional dep — `_check_dependencies()` pattern for graceful fallback
- cnn_mineral table: ol/opx/cpx_pct, fa/fs/wo_mol_pct, uncertainties, classical_agreement, method

- **Learnings for future iterations:**
  - Telluric NaN gaps (1.35-1.45, 1.80-2.00 μm) are handled by polynomial fitting — no special gap-bridging needed
  - Band II minimum (~1.95 μm) often falls in telluric mask — polynomial interpolates through the gap
  - PRD Fa/Fs linear formulas give low values compared to literature; ol/(ol+px) from BAR is the most reliable Dunn output
  - scipy.optimize.minimize_scalar with method='bounded' works well for polynomial minima in bounded wavelength ranges
  - analyze_all follows same pattern as classify_all: query eligible, try each, catch exceptions, commit at end
  - Synthetic Gaussian absorption bands make good test spectra — controllable center, depth, width

## 2026-02-23 — near-earth-muo: space-weathering-correction
- Created `prospector/spectral/weathering.py`: Stage 1B Brunetto et al. (2006) space weathering correction
- Key functions: `fit_cs()` (Cs parameter from continuum slope), `deweather_spectrum()` (apply correction), `deweather_asteroid()` (DB integration), `deweather_all()` (batch)
- Brunetto model: R_observed(λ) = R_fresh(λ) × exp(Cs/λ); Cs < 0 for reddening/darkening
- Cs fitting: least-squares regression of ln(R_norm) vs 1/λ in three continuum regions (0.50-0.70, 1.25-1.35, 2.20-2.50 μm)
- Sanity bounds: Cs ∈ [-2.0, 0.1] μm; insufficient continuum points returns None
- Only applies to silicate classes: {S, Q, K, A, L, O, R, V}
- Added `weathering_cs` (REAL) and `deweathered` (BLOB) columns to spectra table via schema migration
- Migration: `_add_column_if_missing()` pattern in db.py — uses PRAGMA table_info to check, ALTER TABLE to add
- Preserves original reflectance — deweathered stored separately for downstream use
- 31 tests in `tests/test_spectral_weathering.py`: Cs fitting, roundtrip recovery, DB integration, batch, schema migration, physical sanity
- **Learnings for future iterations:**
  - Schema migration pattern: `_add_column_if_missing(conn, table, column, type)` — safe for re-running
  - Brunetto Cs typically -0.5 to 0.0 for real asteroids; -0.15 is moderate weathering
  - Absorption bands don't interfere with Cs fitting because we use continuum-only regions
  - band_analysis should check for `deweathered` column and prefer it when available
  - `from prospector.spectral.weathering import deweather_all, fit_cs, deweather_spectrum`

## 2026-02-23 — near-earth-n40: curve-matching
- Created `prospector/spectral/curve_match.py`: Stage 3 meteorite analog curve matching

- Helpers: `_resample_to_overlap()`, `_best_scale_factor()`, `_taxonomy_weight()`
- Method: resample to overlap grid → free scaling α=(ast·lab)/(lab·lab) → WMSE + correlation ρ
- Rank by WMSE ascending, reject ρ < 0.90 (PRD Option A)
- Taxonomy-consistency filter: prob_vector weighted by TAXONOMY_METEORITE_MAP compatibility
- Prefers deweathered spectrum when available (checks spectra.deweathered column)

- 35 tests in `tests/test_spectral_curve_match.py`: resampling, scaling, scoring, taxonomy weights, DB integration, physical sanity
- **Learnings for future iterations:**
  - Free scaling handles albedo mismatch: α minimizes ||ast - α*lab||² analytically
  - Constant spectra (featureless M-type matching featureless iron) need special rho handling: rho=1.0 if WMSE≈0
  - RELAB spectra may have different wavelength grids → resample via scipy.interpolate.interp1d
  - MIN_OVERLAP_POINTS=20 ensures statistical significance in match metrics
